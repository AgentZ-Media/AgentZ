ScriptZ v0.8.3 - A new Inbox folder surfaces everything that isn't filed away yet.

## What's new

- **Inbox folder for scripts and ideas.** Once you have at least one
  folder, a new "Inbox" chip appears next to "All". It collects
  everything that isn't sorted into a folder yet, so you always have a
  clear view of what still needs filing. It works the same way in both
  the scripts browser and the ideas view, and its counter shows how many
  loose items are waiting. Drag a script onto the Inbox to pull it back
  out of its folder; a new script or idea created while the Inbox is
  active simply stays unfiled.

## Updating

Click the green update pill in the file-browser footer to install
v0.8.3 in place.
