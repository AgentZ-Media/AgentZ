ScriptZ v0.7.9 - Drag scripts back into folders, and a context-menu fix.

## Bug fixes

- **Drag-and-drop scripts onto folder chips works again.** In both
  the list view and the grid view, you can now grab a script and drop
  it on any folder chip to move it there - exactly like it worked in
  the original folders release. The drop targets were still wired up,
  but the drag source had silently dropped off the cards and rows in
  a later refactor, so nothing happened when you tried to drag. The
  dragged item dims to make the source obvious, and the chip
  highlights as a drop target while you hover.
- **Right-click submenus stay inside the window.** When you opened
  the context menu near the bottom of the app, the root menu correctly
  clamped to the bottom edge, but a submenu like "Move to folder"
  could still drop below the window so its last entries were cut off.
  Submenus now flip up the same way the root menu does and always
  stay fully visible.

## Updating

Click the green update pill in the file-browser footer to install
v0.7.9 in place.
