ScriptZ v0.7.3 - Endless writing surface instead of an A4 page stack.

## What's new

- **Endless writing surface in the editor.** The editor is now one
  continuous sheet of paper that grows with your content - no more
  artificial A4 page breaks while writing. For TikTok, Reels and
  Shorts scripts you think in runtime, not in pages. PDF export still
  paginates cleanly on A4 with widow and orphan control, so the
  printed script looks professional.
- **Focus mode: tab bar stays fully visible.** It used to dim itself
  to 40% opacity, which felt more like a bug than a feature. Now it
  stays crisp - focus is carried by the toolbar and cast rail
  hiding, which still happens.
- **Stats more focused.** The cast panel now shows only runtime,
  words and dialog words. The A4 page count is out, because for
  short-form it added no value.

## Bug fixes

- **Character and block dropdowns no longer cover the bars.** When
  you scrolled down in a script and the autocomplete dropdown opened
  above the cursor, it used to sit over the top tab bar and over the
  editor toolbar with the block pills. Dropdowns now slide cleanly
  underneath the bars.

## Updating

Click the green update pill in the file-browser footer to install
v0.7.3 in place.
