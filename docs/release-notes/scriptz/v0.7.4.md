ScriptZ v0.7.4 - Browser test editor, dark paper, and PDF highlighting that matches the editor.

## What's new

- **ScriptZ now runs in the browser, too.** A full browser version
  lives at [app.write-scriptz.com](https://app.write-scriptz.com) -
  same editor, same hotkeys, same PDF export, same `.scriptz`
  container file to move work between desktop and web. Handy for
  trying it out before downloading or if you're briefly on someone
  else's machine. Data lives in the browser (IndexedDB) and isn't
  quite as persistent as the desktop database - the web app says so
  honestly with a banner. Regular writers should stick with the
  desktop app.
- **Theme follows the system.** When the OS flips to dark mode (e.g.
  via the macOS evening automation), ScriptZ now switches with it -
  previously the editor stayed in whichever mode was active at launch.
- **Dark paper.** New in settings: dark paper instead of light in the
  editor. For long evening writing sessions, or if you want to
  visually separate the editor from the rest of your workflow.
  Character highlighting adapts automatically - instead of mixing
  towards white, it blends against the dark paper, keeping the
  contrast against the text intact.

## Bug fixes

- **PDF character highlighting now looks just like in the editor.**
  The colored pills behind character names and dialog used to be
  boxy, slightly too tall, and ended on a rounded monospace
  approximation of the word width. Now: rounded corners, slimmer
  geometry that cleanly wraps the descenders of g/p/y/ß, and the
  pill ends exactly where the word visually ends (real glyph
  width). Editor and export look 1:1 identical.
- **Export dialog remembers the script's highlight setting.** If the
  current script has character highlighting on, the checkbox in the
  export dialog is now pre-ticked (previously it always pulled the
  global default, regardless of the script's own setting).
- **Real umlauts in app texts.** A few `ae/oe/ue/ss` ASCII fallbacks
  had survived in release notes, tooltips and status strings. All
  swept, now consistently `ä/ö/ü/ß`.
