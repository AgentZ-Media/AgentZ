ScriptZ v0.6.2 - Focus mode on by default, your own dialog WPM, better search.

## What's new

**Focus mode on by default**
- New scripts now open directly in focus mode: toolbar and cast
  rail are off, the paper stands on its own. If you want the old
  mode back, flip it permanently in Settings → Appearance.
- Both eye buttons (in the toolbar and the floating eye in the
  top right) now share the same motif - outline for "turn on",
  filled for "active".

**Configurable speaking rate (WPM)**
- The runtime estimate in the cast rail used to assume a fixed
  210 words per minute. It now sits in the settings (Editor tab)
  and ranges from 80 to 400 - fast sketches get a different value
  than calm documentary scripts.

**Cmd+K search finally shows the hit**
- The spotlight search (`⌘K`) used to print the script title twice
  and hide the actual match. Now it shows a snippet of the script
  content with the matched word highlighted - even on long match
  lines, the matched word stays visible.

## Bug fixes

- Inputs in settings fields (e.g. WPM, daily goal) were lost when
  closing the modal directly from the input via Escape, backdrop
  click, or the X button. The value is now committed cleanly
  before close.
- In focus mode, an empty strip used to remain at the top where
  the toolbar sat. It's now removed from the layout entirely.

## Updating

Click the green update pill in the file-browser footer to install
v0.6.2 in place. On the first script opened after the update, the
new default focus mode kicks in right away.
