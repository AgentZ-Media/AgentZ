ScriptZ v0.7.2 - Focus mode remembers what you set per script.

## Bug fixes

- **Focus mode now stays off when you turn it off.** Users who had
  focus mode on by default but turned it off manually on a specific
  script saw it come back on after every tab switch. The manually-set
  state is now persisted per script and survives app restarts - just
  like highlighting and quick mode already did.

## Updating

Click the green update pill in the file-browser footer to install
v0.7.2 in place.
