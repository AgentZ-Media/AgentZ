ScriptZ v0.7.11 - Character tints land instantly, Tab dropdown stops adding stray lines.

## Bug fixes

- **Character and dialog tints appear the moment you press Enter.**
  Before, the colour behind a character name and its dialog only
  filled in after you paused between keystrokes - if you typed the
  name, hit Enter, and immediately kept writing the line, both
  blocks stayed grey. The live character list was waiting for the
  250 ms auto-save debounce, which never fired while you were
  still typing. The list is now updated synchronously on every
  edit, so the tint shows up the instant the cursor leaves the
  character block. Returning characters get their canonical colour
  from the local cache without a save roundtrip.
- **The Tab block-type picker no longer adds an extra blank line.**
  When you opened the picker with Tab, navigated with the arrow
  keys, and confirmed with Enter, the block was correctly
  reformatted but a fresh empty block was inserted below it. The
  Enter key was being handled twice - once by the dropdown, once
  by the editor's own smart-Enter handler. Confirming from the
  keyboard now behaves exactly like clicking with the mouse.
