ScriptZ v0.6.0 - Writing motivation, ideas inbox, and a new editor layout.

## What's new

**Writing motivation, without push notifications**
- **Daily goal + streak pill** in the tab bar - words today, streak
  in days, configurable in the settings.
- **Activity heatmap** (GitHub-style, 365 days) on the overview,
  including a detail modal with year stats.
- **Momentum strip** on the home view - streak, daily progress, and
  a "keep writing" button that returns to the last open script.
- **Sprint timer** in the bottom right of the editor: 5 / 15 /
  25 minutes Pomodoro for writing, with a progress bar.

**Ideas inbox**
- `⌘I` from any view opens quick capture - type the idea, Enter
  saves, you're back in the current script.
- A dedicated **Ideas drawer** with three tabs (Open, All, Used),
  grouped by Today / Yesterday / This Week / Older.
- **One-click conversion** idea → new script (`⌘↵` in the drawer).
  Notes land automatically in the first ACTION block.

**Cast rail in the editor**
- **Cast tab** on the right of the editor shows every character
  with their dialog share as a tinted bar (same color as in the
  PDF).
- **Script statistics**: estimated runtime, words, A4 pages, raw
  dialog words.
- **Versions tab** in the same panel - snapshot history no longer
  hidden in a modal.

**Editor toolbar redesigned**
- Inline title editor, 7 block pills with shortcuts (`⌘1`–`⌘7`),
  quick mode, highlight and focus toggles, export button - all in
  one row.

## Bug fixes

- Data-loss protection on "clear script completely" - the previous
  empty-state guard was blocking legitimate user saves.
- "Today" / "Yesterday" on the overview now follows calendar days
  instead of rolling 24-hour windows.
- Idea-to-script conversion is atomic (CAS reservation) - a double
  click no longer creates a second script.
- Word-count statistics are race-safe: two parallel saves of the
  same script can no longer double-count `daily_word_log`.
- Some a11y fixes: open scripts via Enter/Space, row menu visible
  via keyboard too, tab-bar markup without nested buttons.

## Updating

If you already have v0.5.0 installed, you'll see the green update
pill in the file-browser footer within ~60 min - click installs in
place. The `xattr` step below is only needed for the very first
installation.
