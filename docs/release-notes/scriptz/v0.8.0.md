ScriptZ v0.8.0 - Calmer surface, opt-in writing stats, safer save loop.

## What's new

- **Onboarding lands you in the tutorial.** The final card now has a
  single "Let's go" button that opens the welcome script directly in
  the editor. Before, the script was created but stayed unopened in
  the overview, so most people never saw it. The button is also
  guarded against double-clicks.

- **Writing stats are off by default.** The home-screen "continue
  writing" strip, the streak flame in the title bar, the weekly word
  goal, and the activity heatmap are now hidden out of the box. Short
  scripts live from idea spikes, not daily streak discipline - the
  stats made the app feel like a productivity tool instead of a
  writing tool. They're still there: a single switch under
  Settings → Editor → "Show writing stats" brings them back, and the
  weekly-goal field reappears below it.

- **Save status is honest.** The "Saved" indicator in the title bar
  is now a live status: green when idle, grey-pulsing while a save is
  in flight, red with "Not saved" when the last save attempt failed.
  The first failure in a session also raises a toast, so you find out
  even if you weren't looking at the strip.

- **Boot recovery screen.** If the database can't be opened on
  startup (permission issue, corrupted file, schema mismatch from a
  downgraded build), ScriptZ now shows a blocking recovery screen
  with the actual error message and a retry button - instead of
  falling through to a normal-looking UI where every follow-up
  operation throws "not found" errors and you'd be convinced your
  scripts are gone.

## Bug fixes

- **The empty-editor hint is now bilingual.** "Start typing · Tab
  switches block type · ⌘1–⌘7 direct" used to be hardcoded German;
  English users saw German.

- **Validation errors come through in your language.** Trying to
  create an unnamed folder or idea used to surface a hardcoded
  English error string in the toast; now translated.

- **No more silent data loss when the save loop hits a conflict.**
  After 5 conflicting save attempts, ScriptZ now writes the content
  unconditionally as a last-resort fallback instead of giving up
  quietly. The script body is always saved; only the daily-stats
  delta is skipped (and self-corrects on the next save).

- **The auto-snapshot loop no longer leaves a hole when a snapshot
  fails.** The dirty flag is now cleared only after the snapshot
  actually succeeded, so a transient failure retries on the next
  five-minute tick instead of silently waiting for the next edit.

- **The auto-updater drains pending writes before relaunch.** The
  last 250 ms of typing used to be lost when you clicked the update
  pill mid-edit; now ScriptZ flushes everything before the restart.

## Removed

- **Sprint timer is gone.** The 5/15/25-minute Pomodoro pill was
  never the writing aid we hoped it would be (no audio cue, no real
  cycle), and it pulled focus away from the actual editor. ⌘K + a
  good headphone are still the best sprint timer ScriptZ can offer.

## Under the hood

- The four largest UI components (Browser, Editor, Settings, Ideas
  view) were broken up into focused submodules. No user-visible
  change, but the next contributor will thank us.

## Updating

Click the green update pill in the file-browser footer to install
v0.8.0 in place.
