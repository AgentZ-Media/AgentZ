ScriptZ v0.7.12 - Calmer script list, cleaner folder picker in the New Script dialog.

## What's new

- **The folder picker in the New Script dialog is now a custom
  dropdown.** The native OS select-popup felt out of place inside the
  styled modal - jumping in with a different look and a different
  scroll behaviour. The new picker uses the same shape and shadow as
  the rest of the dialog, opens with the keyboard the same way the
  native one did (Space or arrow keys open it, arrows navigate, Enter
  confirms, Escape closes), and floats above the modal instead of
  forcing its content to scroll.

## Bug fixes

- **Hovering over a script in the list no longer makes the row
  shudder.** The thin colour stripe on the left of each row used to
  grow from 28 px to 36 px on hover, which nudged the row a few
  pixels taller and made the whole list feel jittery when you moved
  the mouse across it. The stripe now stays a constant height; only
  the row background still highlights on hover.

## Updating

Click the green update pill in the file-browser footer to install
v0.7.12 in place.
