ScriptZ v0.7.7 - Parenthetical trigger without a ghost blank line.

## Bug fixes

- **Parenthetical at the start of a dialog line no longer leaves a
  blank line behind.** If you placed the cursor at the beginning of an
  existing dialog line and typed `(`, you previously got an empty
  dialog block stuck between the character and the new parenthetical -
  visible as an extra gap. The original block is now removed when its
  entire content has moved into the new dialog line below the
  parenthetical.

## Updating

Click the green update pill in the file-browser footer to install
v0.7.7 in place.
