ScriptZ v0.7.1 - Runtime in the overview now matches the editor.

## Bug fixes

- **Runtime in the script overview was too long.** The table and card
  views divided all words (including character names, action lines,
  captions and SFX) by the dialog WPM and therefore showed noticeably
  longer runtimes than the editor itself. Both displays now compute
  identically: dialog words / WPM, plus 2 seconds per action or
  camera block. Existing scripts get re-measured once on first launch
  after the update.

## Updating

Click the green update pill in the file-browser footer to install
v0.7.1 in place. On first launch after the update, the app aligns
runtime values for all existing scripts once - runs in the
background, nothing blocks.
