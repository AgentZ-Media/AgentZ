ScriptZ v0.10.1 - Optional nightly updates

## What's new

- **Optional nightly updates:** enable "Receive nightly builds" under Settings > Updates to try upcoming changes before the next stable release. Stable updates remain the default.
- **Automatic backups:** before installing an update from, to or between nightly builds, ScriptZ backs up its database and keeps the five most recent backups. If the backup fails, the update is stopped.
- **Recognizable nightly builds:** nightly versions have a starry sidebar and loading screen, a nightly badge, a dedicated app icon, and build details under About.
- **Return to stable updates:** turn nightly updates off to wait for the next newer stable version. The nightly channel also checks for stable releases and offers the newer version automatically.

## Updating

Install the update from the app's update indicator, or download the installer below.
