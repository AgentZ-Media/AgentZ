ScriptZ v0.7.8 - Now on Windows, too.

## What's new

- **Windows support.** ScriptZ now runs natively on Windows 10 and
  Windows 11 (x64). NSIS installer, double-click to install, no admin
  required, and auto-updates work cross-platform exactly like on macOS.
- **Platform detection on the landing.** write-scriptz.com now detects
  your operating system automatically and offers the matching download
  (.dmg for macOS, .exe for Windows). A discreet "all downloads on
  GitHub" link sits under each button in case detection gets it wrong
  or you want a different platform.
- **Per-platform install hint.** macOS still gets the `xattr` one-liner
  for Gatekeeper; Windows gets the SmartScreen walkthrough ("More info"
  → "Run anyway"). Both are normal for unsigned open-source apps -
  code-signing certificates cost money, and until that pays off, the
  extra clicks are the price ScriptZ pays to stay free and
  account-less.

## Under the hood

- Release pipeline rebuilt into four jobs: macOS first, then Windows,
  both targeting the same GitHub release. The `latest.json` updater
  manifest is automatically merged with the Windows entry. Vercel only
  gets triggered after both builds finish, so the landing picks up the
  new asset URLs in one pass.
- Tauri config gained a `bundle.windows` block with NSIS in
  `currentUser` mode (no admin prompt on auto-updates) and a WebView2
  bootstrapper as a fallback for older Windows 10 versions.

## Updating

Click the green update pill in the file-browser footer to install
v0.7.8 in place. On Windows the NSIS silent installer handles the
update, and SmartScreen doesn't show up again on updates.
