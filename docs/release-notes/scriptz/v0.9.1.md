ScriptZ v0.9.1 - Update channel validation

## What is new

- Validation release for the new ScriptZ-specific update channel introduced in 0.9.0.
- Editor behavior, scripts, settings and storage format are unchanged from 0.9.0.

## Updating

Install this update from ScriptZ 0.9.0 to use the new signed update channel. Installations on 0.8.4 need the new installer once; your existing local data is retained.
