ScriptZ v0.8.1 - Ideas live in folders now, and PDF export keeps your formatting.

## What's new

- **Ideas can live in folders.** Your ideas inbox now shares the same
  folders as your scripts, so a "Client X" folder can hold that
  client's ideas *and* their scripts side by side. Assign a folder
  right when you capture an idea, or move an existing one later with
  the new "Move to folder" action on the idea card. Ideas without a
  folder behave exactly as before, and deleting a folder simply drops
  its ideas back to "No folder" instead of taking them with it.

- **Converting an idea keeps it in place.** Turning an idea into a
  script now pre-selects the folder the idea already lived in, so the
  new script lands in the same client or project folder instead of the
  root. You can still pick a different folder in the dialog.

- **Quick actions in the empty browser.** The script browser now
  offers "New script" and "New folder" straight from the canvas, so
  starting from an empty overview takes one click instead of hunting
  for the right button.

## Bug fixes

- **PDF export keeps your inline formatting.** Bold and italic runs
  inside a block now render correctly in the exported PDF instead of
  being flattened to plain text, and character tint pills span the
  full line even when bold or italic glyphs make it slightly wider.
  Block alignment is honored too.

## Updating

Click the green update pill in the file-browser footer to install
v0.8.1 in place.
