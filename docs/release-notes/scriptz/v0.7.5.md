ScriptZ v0.7.5 - Multilingual. German and English, one app.

## What's new

- **Full English UI.** Settings → Appearance has a new language switch
  right at the top: `Deutsch · English · Auto`. Auto follows your
  system (`navigator.language`); English-language macOS users get
  ScriptZ in English automatically, German systems stay in German.
  Switch anytime, instantly, no restart. Onboarding asks for the
  language right in the first step, next to theme - so English
  speakers don't have to navigate a German onboarding first.
- **Tutorial script per language.** The welcome script new users get
  on first launch as an interactive tutorial now exists in German and
  English. The language at first launch decides which variant gets
  seeded - the text becomes yours afterwards and isn't overwritten on
  a later language switch.
- **Platform-aware hotkeys, including in the tutorial.** If you're on
  a Windows or Linux system, the tutorial text now says "Ctrl+N"
  instead of "Cmd+N" - adapting like the rest of the app.
- **Localized sorting.** Script and folder lists now sort by the
  active app language (German sort in the German app, English sort
  in the English one) instead of always sorting in German.
- **Date and number formats follow the language.** "5 min ago" vs.
  "vor 5 Min.", weekdays in the activity heatmap, thousand-separators
  in statistics - everything adapts to the active language.

## Bug fixes

- **Real plural rules instead of fixed German endings.** Streak pill
  ("1 day" / "2 days"), script counter in the browser ("1 script" /
  "3 scripts"), trash confirmation texts and heatmap tooltips now run
  through `Intl.PluralRules` - previously it was a hand-written
  if-1-else plural that would have produced funny sentences in an
  English UI.
- **HTML `lang` attribute on the desktop app was stuck on `en`.** It
  now correctly reflects the active app language on launch - helps
  screen readers and browser translators do the right thing.

## Updating

Click the green update pill in the file-browser footer to install
v0.7.5 in place. On first launch after the update, the app stays in
whichever language you have today - you can switch anytime in
settings.
