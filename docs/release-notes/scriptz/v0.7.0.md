ScriptZ v0.7.0 - Faster in the flow, fewer clicks, fewer modals.

## What's new

**Create directly instead of via modal**
- `⌘N` and the "+" tab button now create a new script **immediately**,
  no intermediate dialog. For "Untitled" scripts, the toolbar is
  forced visible so you can set the title inline as soon as you know
  what the script is about.
- The old new-script modal (with template selection) is gone - every
  previous template was just empty skeleton blocks anyway.

**Slimmer block toolbar**
- Only the three most-used blocks are visible (Action, Character,
  Dialog), each with the hotkey next to it. Parenthetical, Camera,
  Caption and SFX live behind a "+" disclosure button - less visual
  noise during regular writing, still one click (or the matching
  `⌘N` hotkey) away.
- Empty scripts now show a subtle hint in the editor
  ("Cmd+1 for Action, Cmd+2 for Character ..."), so you find the
  hotkeys without a cheat sheet.

**Tab switches without the reload feel**
- Switching between scripts now **preserves scroll position and
  cursor**, remembered separately per script ID. You land exactly
  where you left off - cursor included, even after block edits.
- The switch animation no longer starts from opacity 0, but from a
  gentle cross-fade with a small slide. No longer feels like a
  reload. `prefers-reduced-motion` gets a pure cross-fade without
  slide.

**Characters tab in settings**
- New tab that only appears once you've given at least one character
  a custom color. Lists all such characters with swatch + reset
  button - so you can manage color overrides **app-wide** without
  finding the character in the editor first.
- Color changes are reflected immediately in the live editor, no
  reload.

**Keyboard tab in settings**
- All hotkeys at a glance: General, Editor, Sprint Timer, Snapshots.
  Reference material while learning the app. Customization (yet) not
  supported.

**Weekly goal instead of daily goal**
- "Daily goal" is now a "weekly goal" with a 1,500-word default.
  More realistic for creators whose writing days are rhythmic
  (3 days writing, 4 days research). Existing `daily_word_goal`
  values are migrated (×7 to weekly).
- Streak logic is unchanged - it still counts days where you wrote
  anything at all.

**Onboarding tightened**
- Four steps became two: Theme + highlighting (with live preview),
  and writing defaults. Plus a final card with a "Write first script"
  button that drops you straight into a fresh editor.

**Ideas via tab**
- The "Ideas" tab in the tab bar replaces the separate ideas drawer.
  Same list, one click less.

**Browser list: runtime instead of page count**
- Shows the estimated runtime (using your WPM setting) instead of
  the A4 page count. More realistic for short-form.

## Bug fixes

- **Character dropdown stuck to the viewport** if you scrolled
  without typing. It now re-anchors on scroll and resize and stays
  with the character block.
- **Cursor landed in the wrong node after tab switch** when the
  block contained inline formatting (e.g. bold). The cursor address
  is now stored via a descendant path, not just a block-relative
  offset.
- **Scroll position of the previous script** could carry over to the
  new one on very fast tab switches. The restore loop is now cleanly
  cancelled.
- **Keyboard list in settings** was accidentally rendered twice. Now
  just once.
- **Color swatch in the character block** sometimes disappeared when
  the mouse moved towards the swatch (hover tracker fired
  mouseleave on the writing column). The tracker now lives on the
  paper canvas, which includes the margins.

## Updating

Click the green update pill in the file-browser footer to install
v0.7.0 in place. On first launch the app does not re-trigger
onboarding - existing installations aren't "first run". Old daily
goals are converted to the new weekly goal automatically when
settings are read.
