ScriptZ v0.11.0 - Agent mode, Ida tasks and a new look

## What's new

- **Agent mode:** a new "Ida" page next to the script chat (top of the sidebar, ⌘L outside a script or ⌘⇧L). Start with a folder, a target length and your speaking pace, then find ideas or write a script together.
  - Ideas arrive as numbered cards - save them with a click or just ask in the chat, with undo.
  - Drafts stream live into a side panel with versions, change highlights, a length meter, quoting by selection, discard and copy.
  - "Done" turns the draft into a regular script and can take the conversation along into the script chat.
  - Past sessions are searchable, and "Continue" picks up where you left off.
- **Ida tasks:** check the hook, shorten, raise the pace, sharpen the ending, fact-check or get feedback - from cards in an empty chat, chips at the problem spot, right-click or ⌘K. Suggestion cards show runtime, speaker changes, longest line and when the conflict starts, with a dashed preview right in the script.
- **Hook markers:** 3, 5 and 10 second marks from the first line of dialog, in the page margin and the timeline.
- **Visible learning:** the sidebar and chat show when Ida is about to learn from a script, a toast reports what was learned, and the inspector shows the learning status. Scripts are only relearned after a meaningful change, and you can choose from which stage on Ida learns (Settings > Agent).
- **Export several scripts at once:** "Export as PDF" in the selection bar opens the export dialog with a file list, character colors and title page for all files. PDFs include runtime and page numbers, and the title page choice is remembered.
- **A new look:** a sliding selection in the sidebar, a library with weekly activity, small script thumbnails, cast avatars and runtime bars, paper on a calm desk in the editor, a runtime ring against your target, rolling counters and a small celebration when a script is finished.
- **Typewriter focus:** in focus mode, the line you are writing stays in the middle of the screen (Settings, off by default).
- **Faster with large libraries:** saving updates only the changed script instead of reloading everything, chats stream more smoothly, and new database indexes speed up lists, folders and search.

## Fixes

- Renaming, moving or changing the stage of a script is no longer reverted by an autosave that was still in flight.
- Search finds text in languages without spaces, such as Chinese.
- Draft runtimes count action lines the same way as scripts.
- The sidebar can be expanded again from inside a script, and idea titles in the Inbox use the full width again.

## Updating

Install the update from the app's update indicator, or download the installer below. Your scripts, ideas and settings are kept.
