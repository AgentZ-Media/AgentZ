ScriptZ v0.9.0 - Built on the shared AgentZ Suite foundation.

## What's new

- ScriptZ now shares its design system, settings and desktop infrastructure with future AgentZ tools. Your editor, scripts and workflow stay familiar.
- The yellow ScriptZ icon is now consistent across the app, macOS and Windows installers.
- Native menus follow your German or English language preference.

## Bug fixes

- Closing a window and quitting now wait for pending changes to save; a failed save keeps the app open.
- Update installation saves pending work before an installer can stop the app.
- Reopening the app restores its window, and a second launch focuses the existing instance.

## Updating

This release moves ScriptZ to its own update channel. If you use v0.8.4 or earlier, install v0.9.0 once using the installer below. Your existing local data stays in place. Future updates will appear inside ScriptZ.
