ScriptZ v0.9.2 - Inbox, custom stages and a smarter sidebar

## What's new

- **Inbox:** a new entry at the top of the sidebar collects everything that is still in progress - open ideas and every script before the last stage. It only shows up while there is something to do.
- **Custom stages:** the production stages can now be edited under Settings > Stages. Rename, reorder, add (up to 10) or remove them; scripts of a removed stage move to the previous one. The last stage counts as done.
- **Recent scripts fill the sidebar:** the "Recent" section shows as many recently opened scripts as fit the window height instead of a fixed five.
- **More reliable quitting and saving:** quitting no longer hangs when the window never finished loading, and repeated save errors ask whether to close anyway instead of locking you in.

## Updating

Install the update from the app's update indicator, or download the installer below. Your scripts, ideas and settings are kept.
