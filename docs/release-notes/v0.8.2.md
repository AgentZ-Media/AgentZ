ScriptZ v0.8.2 - Select many scripts at once and batch-export PDFs.

## What's new

- **Multi-select in the browser and ideas.** A new "Select" mode lets
  you tick several scripts (or several ideas) at once. Click "Select",
  check the ones you want, and act on the whole batch. The selection
  resets automatically when you switch folders, search, or leave the
  view, so you never act on a stale set.

- **Batch PDF export.** With multiple scripts selected, "As PDF" now
  exports one clean PDF per script in a single step - pick a target
  folder once and every script lands there with its own title page and
  A4 layout. In the browser version each script downloads individually.

## Bug fixes

- **Selection bar alignment.** The new selection bar now lines up with
  the rest of the browser content instead of stretching to the full
  window width.

## Updating

Click the green update pill in the file-browser footer to install
v0.8.2 in place.
