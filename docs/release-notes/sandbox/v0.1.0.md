Sandbox v0.1.0 - Foundation acceptance preview

## What is included

- Disposable test app generated from the AgentZ Suite foundation.
- Shared desktop shell, light and dark themes, German and English, and isolated app storage.
- Toast and confirmation examples for checking the shared UI.

This published prerelease exists only to verify installers and the independent Sandbox update channel. It will be removed after acceptance. It does not modify ScriptZ data.
