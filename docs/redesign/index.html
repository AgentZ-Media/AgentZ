Was ScriptZ heute ist - und was es werden kann.

Erst die ehrliche Bestandsaufnahme: wie App, Navigation, Ideen, Editor, Overlays und Design-Tokens heute gebaut sind. Dann ein neues Modell für Status statt Workflow-Ordner, ein Plan, wie das Designsystem als eigenes Paket für eine ganze Creator-Suite ausgegliedert wird, und das finale Redesign-Konzept zum Durchklicken.

1 · Architektur heute

Ein pnpm-Monorepo, drei Apps, ein geteilter Core. Desktop und Web sind zwei Schalen um denselben Editor - sie unterscheiden sich nur in ihren Adaptern. Die Landing ist eigenständig.

2 · Navigation & Overlays

Die App ist ein Browser-Fenster mit Tabs. Zwei feste Pseudo-Tabs (Home, Ideen) sitzen links, dahinter beliebig viele Skript-Tabs. Rechts in der gleichen Leiste: Wochenwörter, Streak, Speicherstatus, Zahnrad.

│ ●●●  [⌂ Home] [💡 18] [Skript A ×] [Skript B ×] [Skript C ×] [+]      0 W Woche · ✦ 1 Tag · ● Gespeichert  ⚙ │
└────────────────────────────────────────────────────────────────────────────────────────────────┘
       │          │            │                                   │
       │          │            └─ ScriptView  Toolbar · A4-Papier · Rail (Cast | Versionen)
       │          └─ IdeasView  Eingabe · Suche · Offen/Alle/Verwendet · Karten · "Skript →"
       └─ Browser  Begrüßung · Momentum-Strip · Suche · Liste/Raster · Import · Papierkorb · Neu
                    Ordner-Chips (Alle | Posteingang | Ordner … | + Ordner) · Sortierung · Zeit-Buckets

Overlays (modal, über allem):
  ⌘K  CommandBar      Volltextsuche über Skripte (nur Skripte, keine Befehle)
  ⌘I  QuickCapture    "Neue Idee" · Ordner wählen · ⏎ Merken · ⌘⏎ sofort Skript  (im Fokus-Modus gesperrt)
  ⌘,  Settings        Erscheinungsbild · Editor · Charaktere · Tastatur · Updates · Über
  ⌘E  Export          PDF · Plain Text · .scriptz
  ⌘⇧H Snapshots       Verlauf + Wiederherstellen
  ·    NewScript · Activity (Heatmap) · Onboarding (2 Schritte) · Confirm · Toasts

Tastatur zuerst

Fast alles hat einen Hotkey: ⌘N, ⌘T, ⌘W, ⌘0-9, ⌘⌥←/→, ⌃Tab. Das ist eine Stärke, die jedes Redesign behalten muss.

Fokus-Modus als Default

Beim Öffnen eines Skripts sind Toolbar und Rail weg - nur das Papier und ein Augen-Button. Unbenannte Skripte erzwingen die Toolbar, damit ein Titel kommt.

View-Transitions

Home ↔ Skript und Tab-Wechsel animieren gerichtet (into-script, back-to-browser, forward/backward).

5 · Das Designsystem heute

Es gibt kein eigenständiges Designsystem, sondern drei Token-Sätze, die auseinanderlaufen. Die Primitives (Button, Modal, Pill, Select) leben in global.css des Core.

6 · Befunde

Was beim Durchgehen auffällt, sortiert nach Wirkung.

Logik

Ordner tragen zwei Bedeutungen

Ordner werden für Themen/Kunden und für Arbeitsstand (offen, gedreht) benutzt. Ein Skript kann aber nur in einem Ordner liegen - "Kunde X" und "gedreht" gleichzeitig geht nicht. Fehlt: ein Status.

Logik

Idee und Skript sind getrennte Welten

Nach der Umwandlung bleibt die Idee als "verwendet" liegen, ihre Notizen werden ins Skript kopiert (doppelt). Es gibt keine Sicht, die zeigt: wie viel ist in der Pipeline, was ist drehbereit.

Design

Kein ausgliederbares Designsystem

Mehrere Token-Sätze und Alias-Familien, Primitives in global.css. Für eine Suite muss das ein Paket mit einer Quelle werden.

Navigation

Tab-Leiste macht vier Jobs

Navigation (Home, Ideen), offene Dokumente, Statistik (Woche, Streak) und Speicherstatus teilen sich 38 px Höhe. Für eine Suite mit mehreren Programmen trägt dieses Muster nicht.

Navigation

Home hat fünf Schichten vor dem ersten Skript

Begrüßung → Momentum-Strip → Suche + 5 Buttons → Ordner-Chips → Sortierzeile → Liste. Die Zeilen selbst zeigen wenig (Charaktere, Laufzeit), aber keinen Stand.

Editor

Toolbar wiederholt, was Tastatur schon kann

7 Block-Pills plus Tab-Picker plus ⌘1-7 - drei Wege für dasselbe. Die Rail zeigt "Versionen" nur als Link auf den Snapshot-Dialog.

Editor

⌘I ist im Fokus-Modus gesperrt

Der Fokus-Modus ist Default, also ist Quick-Capture genau beim Schreiben weg - dem Moment, in dem die nächste Idee am häufigsten kommt. README und Landing versprechen "⌘I from anywhere".

Konsistenz

README verspricht einen Sprint-Timer, den es nicht mehr gibt

Im Code von packages/core existiert keine Sprint-Komponente mehr; README (Editor-Abschnitt, Motivation, Vergleichstabelle) und Landing erwähnen ihn noch.

7 · Neue Logik: ein Ding, ein Lebenslauf

Grundlage des Konzepts: Status beschreibt, wo ein Stück gerade steht. Ordner beschreiben, wozu es gehört (Format, Kunde, Serie). Zwei Achsen, die sich nicht mehr in die Quere kommen. Eine Idee ist einfach die erste Stufe. 

Status (fest, fünf Stufen)

  Idee ──▶ Schreiben ──▶ Drehbereit ──▶ Gedreht ──▶ Online
   │            ▲ │                         │
   │            └─┘ zurück jederzeit        └─ optional, wer
   └─ nur Titel + Notiz,                       nichts postet,
      noch kein Papier                         hört bei Gedreht auf

  Papierkorb bleibt orthogonal (archived_at).

Ordner (frei, flach wie heute)
  TikTok-Sketche · Kunde Müller · Serie "Büro" …
  → Ordner verlieren den Job "Arbeitsstand".

Was das konkret bedeutet

  • Neue Spalte scripts.status + status_changed_at. Additive Migration, Default writing, also kein Bestandsskript ändert sein Verhalten.
  • Ideen bleiben vorerst eine eigene Tabelle, werden aber in der UI als Stufe "Idee" gezeigt. Beim Umwandeln wird die Idee zum Skript (Notiz wandert in ein Notizfeld des Skripts statt in den ersten ACTION-Block). Eine echte Zusammenlegung der Tabellen wäre Schritt zwei.
  • Kein Tag-System. Tags, Projekte und globale Charaktere wurden 2026-05 bewusst entfernt. Status ist bewusst eine geschlossene Liste, keine frei definierbaren Labels - sonst sind wir in drei Monaten wieder bei der Ordner-Frage.
  • Wirkung auf Statistik: "Gedreht diese Woche" ist eine Zahl, die Creator wirklich interessiert - mehr als Wörter. Kann die Wochenziel-Logik ergänzen.

8 · Designsystem ausgliedern

Ziel: ein Paket, das jede künftige App der Suite importiert und nur noch über ein Theme (Akzent, ggf. Display-Schrift) individualisiert. Kein Hex-Wert außerhalb dieses Pakets. 

packages/
├ design/            @agentz/design   reines CSS + Tokens, framework-frei
│ ├ tokens/
│ │ ├ primitives.css   Graustufen, Farbrampen, Abstände, Radien, Typo, Motion
│ │ ├ semantic.css     --surface-*, --text-*, --line-*, --accent-*, --status-*
│ │ └ tokens.json      Quelle → generiert CSS + TS (optional)
│ ├ themes/
│ │ ├ scriptz.css      [data-app="scriptz"] Akzent, Papier-Tokens
│ │ └ <app>.css        jede künftige Suite-App
│ ├ components/        button · field · select · menu · popover · modal
│ │                    toast · kbd · badge · segmented · sidebar · list-row
│ ├ fonts/             woff2 + Lizenzen (offline gebundelt)
│ └ icons/             ein SVG-Set statt 8 Inline-Kopien
│
├ ui/                @agentz/ui   Solid-Komponenten auf design/
│                      Sidebar · CommandPalette · Modal · Toast · StatusBadge
│
└ scriptz-core/      heutiges core, nur noch Editor + Domänenlogik

Regeln, damit es sauber bleibt

  • Drei Ebenen: Primitives (Rohwerte) → Semantik (Rollen) → Theme (App-Akzent). Komponenten lesen nur Semantik.
  • Ein Namensraum: --brand-*, --ink-* und --fg/--text werden über eine Alias-Datei auf die neuen Namen gemappt und dann schrittweise entfernt.
  • Stylelint verbietet Hex-Werte außerhalb von packages/design, analog zur bestehenden ESLint-Regel gegen @tauri-apps im Core.
  • Landing darf @agentz/design importieren - es ist reines CSS ohne App-Logik. Damit endet die Kopie in apps/landing/src/styles/tokens.css.
  • Rüberkopieren heißt dann: packages/design kopieren, ein Theme anlegen, fertig.

9 · Das Konzept: Werkbank

Aus drei Richtungen ist eine geworden. Die Werkbank ist die Schale, die für eine Suite mit vielen Programmen skaliert; die Zeitleiste aus dem Taktgeber-Entwurf ist als ausklappbares Panel unter dem Papier eingezogen.

Finales Konzept · 7 Screens, hell und dunkel

Werkbank →

Seitenleiste mit App-Wechsler, Pipeline-Stufen, Ordnern und Zuletzt. Inspector nur für Informationen. Ausklappbare Zeitleiste mit Sprecher-Spuren, Hook und Längenziel. Nur noch vier Blocktypen, endlose Schreibfläche, Wort-Zähler statt Wochenziel, das Punkt-Logo im neuen Design. Dazu Bausteine, Tokens, Tastatur und Feinschliff-Notizen.
