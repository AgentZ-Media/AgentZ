Morgenroutine-Sketch

Drehbereit · 312 Wörter · ca. 1:45 Min.

Ein Schlafzimmer im Morgengrauen. Der Wecker klingelt. Ein Arm tastet sich unter der Decke hervor.

Lena
(ohne die Augen zu öffnen)
Fünf Minuten. Nur noch fünf ganz kleine Minuten.
Wecker
Das hast du vor vierzig Minuten auch gesagt.

Lena setzt sich ruckartig auf und starrt den Wecker an.

Seitenleiste ausblenden zeigt, wo der Hinweis dann bleibt: als kleiner Mond-Chip oben links. Die Sterne funkeln leise, gelegentlich fällt eine Sternschnuppe. Bei „Bewegung reduzieren" steht der Himmel still.

Stündlich automatisch prüfenLäuft die App länger, wird zusätzlich jede Stunde geprüft.
Nightly-Builds erhalten BetaNeue Funktionen, sobald sie fertig sind. Höchstens alle drei Stunden ein frischer Stand, kann Fehler enthalten.
Vor jedem Nightly-Update legt ScriptZ eine Sicherung deiner Skripte an. Fehler gern über GitHub Issues melden.

Umschalten auf „Nightly gerade abgeschaltet" zeigt den Zustand, in dem man noch einen Nightly-Build nutzt, aber zurück auf Stabil will: kein Downgrade, sondern Warten auf die nächste stabile Version.

Nightly-Builds aktivieren?

Du bekommst neue Funktionen früher, aber ungetestet.

  • Es kann etwas kaputt sein. Wichtige Projekte lieber im stabilen Kanal schreiben.
  • Vor jedem Nightly-Update wird automatisch gesichert.
  • Zurück zu Stabil geht jederzeit, sobald die nächste stabile Version erscheint.
